타마포케 한글판 공개 플래셔 사용 안내
======================================

중요 경고
---------
이 플래셔, 공개 저장소 및 릴리스에는 포켓몬 스프라이트와 추가 이미지·음원이
들어 있지 않습니다. 본인이 직접 제작했거나 소프트웨어 삽입·편집·사용 권한을
보유한 파일만 준비하세요.

플래셔가 만든 전체 펌웨어(*-full.bin), Additional_assets.zip, 스프라이트
캐시를 제3자에게 재배포하지 마세요. 완성 펌웨어에는 서로 다른 권리의 코드와
자산이 결합되며, 재배포자는 라이선스 위반이나 권리자의 문제 제기에 대한
책임을 직접 부담할 수 있습니다.

준비 순서
---------
1. TamaPoke-Flasher.exe를 원하는 폴더에 둡니다.
2. 아래 구성으로 Additional_assets.zip을 직접 만들어 같은 폴더에 둡니다.
3. ESP32-S3 기기의 화면이 켜진 상태로 USB-C 데이터 케이블을 연결합니다.
4. 플래셔를 실행하고 새로고침으로 추가 자산 감지를 확인합니다.
5. "자동 확인 후 설치"를 누릅니다.

일반 사용자는 Arduino나 Python을 설치할 필요가 없습니다. 처음 설치할 때
필요한 도구와 스프라이트를 내려받으므로 인터넷 연결이 필요합니다.

Additional_assets.zip 필수 구성
-------------------------------
Visual\L01.png  로딩 화면 (권장 350x350, 검은 배경 합성)
Visual\B01.png  닫힌 포획 볼 (권장 160x160, 검은 배경 합성)
Visual\B02.png  열린 포획 볼 (권장 160x160, 검은 배경 합성)
Visual\S01.png  잠만보 머리·팔, 맨 뒤 레이어 (권장 350x350)
Visual\S02.png  잠만보 몸통, 가운데 레이어 (권장 350x350)
Visual\S03.png  잠만보 발, 맨 앞 레이어 (권장 350x350)
Visual\S04.png  잠에서 깬 잠만보 전체 (권장 350x350)
Visual\D01.png ~ D04.png  디그다 등장 4프레임 (각 22x17 필수)
Visual\DD.png   빈 땅굴 (22x16 필수)

Audio\P.mp3 또는 P.wav        특별 파트너 등장음 (최대 4초 사용)
Audio\Care.mp3 또는 Care.wav  케어 알림음 (최대 10초 사용)
Audio\C.mp3 또는 C.wav        포획 성공음 (최대 10초 사용)
Audio\L.mp3 또는 L.wav        저체력 알림음 (최대 6초 사용)
Audio\E.mp3 또는 E.wav        진화 (6.2초 이상, 1.0초부터 5.2초, 끝 2초 페이드)
Audio\B.mp3 또는 B.wav        작별 (10초 이상, 처음 10초, 끝 2초 페이드)
Audio\BAT.mp3 또는 BAT.wav    배틀 (60초 이상, 처음 60초, 끝 5초 페이드)
Audio\MIN.mp3 또는 MIN.wav    미니게임 (60초 이상, 처음 60초, 끝 5초 페이드)
Audio\MAR.mp3 또는 MAR.wav    통신 짝짓기 (15.5초 이상, 끝 5초 페이드)

ZIP 안에 상위 폴더가 하나 더 있어도 인식하지만 Visual과 Audio 폴더명 및
파일명은 위 표기대로 유지하세요. 대소문자는 구분하지 않습니다. 같은 오디오의
MP3와 WAV를 동시에 넣으면 중복 오류가 납니다.

잠만보 이미지 주의
------------------
S01~S04는 완전히 같은 350x350 캔버스, 같은 원점과 배율로 만드세요. 완성된
그림 한 장을 네 장으로 복제한 뒤 각 레이어에서 필요 없는 부분만 투명하게
지우는 방식이 가장 안전합니다. 부품을 이동시키면 합성할 때 몸이 어긋납니다.

S01(머리·팔)을 먼저 그리고 S02(몸통), S03(발) 순서로 겹칩니다. 일반 타격
때는 S02만 흔들립니다. 100점에 도달하면 세 레이어 대신 S04로 바뀝니다.
S01+S02+S03을 같은 좌표에 겹쳤을 때 완전한 한 장이 보여야 합니다.

설치 및 캐시
------------
처음 설치할 때 플래셔는 SpriteCollab 원본 저장소에서 필요한 1세대
스프라이트와 제작자 크레딧을 직접 내려받고 최적화합니다. 또한 공식 배포된
플래싱·파일시스템 도구를 내려받아 SHA-256으로 검증합니다.

다운로드와 생성 파일은 실행 파일 옆에만 보관됩니다.

TamaPoke-Flasher-Data\
  Cache\      스프라이트 원본/가공본, 크레딧, 추가 자산, 완성 펌웨어
  Payload\    다운로드한 도구와 자산 없는 기본 프로그램
  Logs\       설치 로그
  Backups\    저장 데이터 백업

ZIP 안의 이미지나 음원이 하나라도 바뀌면 내용 해시가 달라져 새 자산과
펌웨어를 만듭니다. 동일한 ZIP·스프라이트·기종 조합은 캐시된 펌웨어를
재사용합니다. 사용자 파일은 외부 서버로 업로드하지 않습니다. 모든 캐시를
지우려면 플래셔를 종료하고 TamaPoke-Flasher-Data 폴더를 삭제하세요.
