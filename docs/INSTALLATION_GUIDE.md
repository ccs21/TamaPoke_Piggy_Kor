# 타마포케 한글판 처음 설치하기

이 문서는 GitHub, 펌웨어, Arduino를 처음 접하는 사용자도 순서대로 따라 할 수
있도록 작성했습니다. 명령어를 입력하거나 Arduino, Python 같은 개발 프로그램을
설치할 필요는 없습니다.

설치 과정은 크게 다음 네 단계입니다.

1. 공개 플래셔의 압축을 풉니다.
2. 샘플 추가 자산 ZIP을 준비합니다.
3. 화면을 켠 ESP32-S3 기기를 USB로 연결합니다.
4. 플래셔에서 `자동 확인 후 설치`를 누릅니다.

## 1. 설치 전에 알아둘 것

타마포케 한글판 설치에는 다음 두 파일이 필요합니다.

```text
TamaPoke-Flasher.exe
Additional_assets.zip
```

`TamaPoke-Flasher.exe`는 필요한 파일을 내려받고, 연결된 기종에 맞는 펌웨어를
만든 뒤 기기에 설치하는 프로그램입니다.

`Additional_assets.zip`에는 로딩 화면, 포획 화면, 일부 미니게임 이미지와
선택적인 음원이 들어갑니다.

포켓몬 151종의 일반·이로치 스프라이트는 `Additional_assets.zip`에 넣지
않습니다. 플래셔가 설치 과정에서 원본 제공처로부터 자동으로 내려받습니다.

## 2. 준비물

다음 항목을 준비하세요.

- Windows 10 또는 Windows 11 PC
- Waveshare ESP32-S3-Touch-AMOLED-1.75 또는 1.75C
- 데이터 전송이 가능한 USB-C 케이블
- 인터넷 연결
- 공개 플래셔
- 샘플 추가 자산 ZIP

충전 전용 USB 케이블은 사용할 수 없습니다. 충전은 되는데 플래셔에 기기가
표시되지 않는다면 다른 USB 케이블을 사용해 보세요.

## 3. 설치 폴더 만들기

먼저 플래셔와 자산 파일을 모아둘 새 폴더를 만듭니다. 예를 들면 다음 위치를
사용할 수 있습니다.

```text
C:\TamaPoke-Installer
```

바탕 화면이나 다운로드 폴더를 사용해도 되지만, 파일을 나중에 다시 찾기 쉽도록
별도의 폴더를 만드는 편이 좋습니다.

설치 준비가 끝난 폴더는 다음처럼 보여야 합니다.

```text
C:\TamaPoke-Installer
├─ TamaPoke-Flasher.exe
└─ Additional_assets.zip
```

두 파일은 반드시 같은 폴더에 있어야 합니다.

## 4. 공개 플래셔 내려받기

1. [GitHub 릴리스 페이지](https://github.com/ccs21/TamaPoke_Piggy_Kor/releases/latest)를 엽니다.
2. 최신 공개 플래셔 ZIP을 내려받습니다.
3. 내려받은 ZIP을 마우스 오른쪽 버튼으로 누릅니다.
4. `압축 풀기` 또는 `모두 압축 풀기`를 선택합니다.
5. 압축을 푼 폴더에서 `TamaPoke-Flasher.exe`를 찾습니다.
6. 이 파일을 앞에서 만든 설치 폴더에 넣습니다.

ZIP 파일 안에서 프로그램을 바로 실행하지 마세요. 반드시 압축을 먼저 풀어야
합니다.

## 5. 샘플 추가 자산 준비하기

1. [sample_Additional_assets.zip](../samples/sample_Additional_assets.zip)을 내려받습니다.
2. 파일을 `TamaPoke-Flasher.exe`가 있는 폴더에 복사합니다.
3. 파일 이름을 `Additional_assets.zip`으로 변경합니다.

```text
변경 전: sample_Additional_assets.zip
변경 후: Additional_assets.zip
```

다음처럼 이름이 잘못되지 않았는지 확인하세요.

```text
Additional_assets.zip.zip
Additional_assets (1).zip
sample_Additional_assets.zip
```

### 파일 확장자가 보이지 않을 때

Windows에서 `.zip`, `.png`, `.mp3` 같은 부분이 보이지 않는다면 다음 순서로
파일 확장명 표시를 켭니다.

1. 파일 탐색기를 엽니다.
2. 상단의 `보기`를 누릅니다.
3. `표시`를 누릅니다.
4. `파일 확장명`을 켭니다.

## 6. 샘플 이미지를 그대로 사용하기

이미지를 직접 만들기 어렵다면 샘플 ZIP을 수정하지 않고 그대로 사용할 수
있습니다.

샘플에는 다음 기능을 확인하기 위한 기본 이미지가 들어 있습니다.

- 슬립 복귀 로딩 화면
- 포획용 닫힌 볼과 열린 볼
- 잠만보 터치 미니게임용 레이어
- 잠에서 깬 결과 이미지
- 뿅뿅디그다용 4개 등장 프레임
- 빈 땅굴

샘플 이미지는 파일 구조와 기능 확인을 위해 ccs21이 직접 제작한 비공식 대체
이미지입니다. 공식 게임에서 추출한 이미지가 아닙니다. 원하는 경우 자신이 만든
이미지로 교체할 수 있습니다.

## 7. 샘플 ZIP의 폴더 구조

샘플 ZIP의 압축을 풀면 `Visual`과 `Audio` 폴더가 있습니다.

```text
Additional_assets.zip
├─ Visual
│  ├─ L01.png
│  ├─ B01.png
│  ├─ B02.png
│  ├─ S01.png
│  ├─ S02.png
│  ├─ S03.png
│  ├─ S04.png
│  ├─ D01.png
│  ├─ D02.png
│  ├─ D03.png
│  ├─ D04.png
│  └─ DD.png
└─ Audio
   ├─ P.mp3
   ├─ Care.mp3
   ├─ C.mp3
   ├─ L.mp3
   ├─ E.mp3
   ├─ B.mp3
   ├─ BAT.wav
   ├─ Min.wav
   └─ MAR.wav
```

파일 이름을 임의로 바꾸면 플래셔가 찾지 못합니다. 그림이나 음원 내용만
교체하고 이름은 그대로 유지하세요.

## 8. 이미지를 직접 교체하는 방법

샘플 이미지를 그대로 사용한다면 이 장은 건너뛰어도 됩니다.

이미지를 바꾸려면 `sample_Additional_assets.zip`의 압축을 먼저 풉니다. 그림
편집 프로그램에서 해당 PNG를 열어 수정한 뒤 같은 이름으로 저장하세요.

### 이미지 공통 주의사항

- 파일 형식은 PNG를 사용합니다.
- 파일 이름을 바꾸지 않습니다.
- 얇은 반투명 테두리는 축소 후 지저분하게 보일 수 있습니다.
- 중요한 그림과 글자를 이미지 가장자리에 붙이지 않습니다.
- 투명 배경이 필요한 그림은 흰색이 아니라 알파 투명 배경으로 저장합니다.

그림 편집 프로그램에서 투명 영역은 보통 회색과 흰색의 바둑판무늬로
표시됩니다.

### L01.png — 로딩 화면

- 권장 크기: 350×350
- 슬립 상태에서 기기를 깨울 때 표시
- 검은 배경과 합성
- 글자와 주요 그림은 가장자리에서 20픽셀 이상 안쪽에 배치 권장

### B01.png — 닫힌 포획 도구

- 권장 크기: 160×160
- 포획 연출에서 닫힌 상태로 표시
- 검은 배경과 합성

### B02.png — 열린 포획 도구

- 권장 크기: 160×160
- 포획에 실패했을 때 표시
- `B01.png`와 같은 캔버스와 중심점 사용

`B01.png`와 `B02.png`의 그림 위치가 다르면 포획 연출 중 그림이 순간이동하는
것처럼 보일 수 있습니다. 같은 캔버스에서 닫힌 모습과 열린 모습을 각각 만드는
것이 가장 쉽습니다.

### S01.png — 머리와 팔 레이어

- 권장 크기: 350×350
- 잠만보 터치 미니게임에서 가장 뒤에 표시
- 배경은 투명하게 준비

### S02.png — 몸통 레이어

- 권장 크기: 350×350
- `S01` 위에 표시
- 일반 타격 때 이 레이어가 흔들림
- 배경은 투명하게 준비

### S03.png — 발 레이어

- 권장 크기: 350×350
- 가장 앞에 표시
- 배경은 투명하게 준비

`S01`, `S02`, `S03`은 반드시 같은 크기와 같은 위치를 사용해야 합니다. 세
파일을 겹쳤을 때 하나의 완성된 그림이 되어야 합니다.

```text
맨 앞: S03.png
가운데: S02.png
맨 뒤: S01.png
```

가장 쉬운 제작 순서:

1. 350×350 크기의 완성된 그림을 하나 준비합니다.
2. 그림 파일을 세 번 복사합니다.
3. 첫 번째 파일에서는 머리와 팔만 남기고 나머지를 지웁니다.
4. 두 번째 파일에서는 몸통만 남깁니다.
5. 세 번째 파일에서는 발만 남깁니다.
6. 남은 부분의 위치를 움직이지 않습니다.
7. 각각 `S01.png`, `S02.png`, `S03.png`로 저장합니다.

각 부분을 따로 잘라 가운데 정렬하면 합쳤을 때 위치가 어긋날 수 있습니다.

### S04.png — 성공 결과 이미지

- 권장 크기: 350×350
- 미니게임 목표 점수에 도달했을 때 표시
- 한 장으로 완성된 그림
- 배경은 투명하게 준비

### D01.png~D04.png — 등장 애니메이션

다음 네 파일은 뿅뿅디그다에서 캐릭터가 구멍에서 올라오는 순서로 사용합니다.

```text
D01.png → D02.png → D03.png → D04.png
```

네 파일은 반드시 정확히 22×17픽셀이어야 합니다.

- `D01`: 거의 숨어 있는 모습
- `D02`: 조금 올라온 모습
- `D03`: 대부분 올라온 모습
- `D04`: 완전히 올라온 모습

모든 프레임에서 구멍과 캐릭터의 중심 위치를 같은 x좌표에 맞추세요. 프레임마다
구멍 위치가 달라지면 게임에서 그림이 흔들려 보입니다.

### DD.png — 빈 구멍

- 필수 크기: 22×16픽셀
- 캐릭터가 나오지 않은 빈 구멍
- 배경은 투명하게 준비

더 자세한 자산 규격은 [Additional_assets.zip 상세 제작 안내](ADDITIONAL_ASSETS_GUIDE.md)를
확인하세요.

## 9. 오디오 파일을 사용하지 않는 방법

샘플 ZIP 안의 오디오 파일은 이름과 위치를 알려주기 위한 0바이트 표시
파일입니다.

0바이트 오디오 파일은 오류가 아닙니다. 플래셔는 해당 음원을 사용하지 않는
것으로 처리합니다. 음원을 준비하지 못했다면 파일을 그대로 두면 됩니다.

이 경우 장면에 따라 펌웨어의 기본 합성 효과음이 나오거나 BGM 없이 진행됩니다.
게임 진행에는 문제가 없습니다.

## 10. 원하는 오디오를 넣는 방법

오디오를 사용하지 않는다면 이 장은 건너뛰어도 됩니다.

원하는 음원을 준비했다면 같은 이름의 0바이트 파일을 실제 MP3 또는 WAV로
교체하세요. 직접 제작했거나 소프트웨어 삽입과 변형을 허락받은 음원만 사용해야
합니다.

MP3와 WAV 중 하나만 넣어야 합니다. 예를 들어 `BAT.mp3`와 `BAT.wav`를 동시에
넣으면 중복 오류가 발생합니다.

확장자를 바꿨다면 기존 0바이트 파일을 반드시 삭제하세요.

```text
잘못된 예
├─ BAT.wav       ← 빈 표시 파일
└─ BAT.mp3       ← 실제 음원

올바른 예
└─ BAT.mp3       ← 실제 음원 하나만 존재
```

Windows가 확장자를 숨긴 상태에서 `BAT.wav.mp3`처럼 이중 확장자가 생기지 않도록
주의하세요.

## 11. 수정한 폴더를 다시 ZIP으로 만들기

이미지나 음원을 바꿨다면 다음 순서로 다시 압축합니다.

1. 압축을 풀어둔 폴더를 엽니다.
2. `Visual`과 `Audio` 두 폴더를 함께 선택합니다.
3. 마우스 오른쪽 버튼을 누릅니다.
4. `ZIP 파일로 압축`을 선택합니다.
5. 만들어진 ZIP 이름을 `Additional_assets.zip`으로 변경합니다.
6. `TamaPoke-Flasher.exe`와 같은 폴더에 넣습니다.

ZIP을 열었을 때 가장 먼저 `Visual`과 `Audio` 두 폴더가 보이는 것이 가장
안전합니다.

다음처럼 ZIP 안에 다른 ZIP을 넣으면 안 됩니다.

```text
Additional_assets.zip
└─ sample_Additional_assets.zip
```

## 12. 기기를 PC에 연결하기

기기의 화면을 먼저 켭니다. 슬립 상태에서는 일부 회로가 꺼져 있어 PC가 기기를
정상적으로 찾지 못할 수 있습니다.

1. 기기의 PWR 버튼을 눌러 화면을 켭니다.
2. 메인 화면이 표시되는지 확인합니다.
3. USB-C 데이터 케이블로 PC와 연결합니다.
4. Windows가 기기를 인식할 때까지 잠시 기다립니다.

## 13. 플래셔 실행하기

1. `TamaPoke-Flasher.exe`를 실행합니다.
2. `새로고침` 버튼을 누릅니다.
3. 추가 이미지와 음원 상태가 정상으로 표시되는지 확인합니다.
4. 연결된 COM 포트를 확인합니다.
5. `자동 확인 후 설치` 버튼을 누릅니다.

1.75와 1.75C는 플래시 메모리 용량을 검사해 자동으로 구분합니다.

처음 실행할 때 Windows가 알 수 없는 프로그램이라는 경고를 표시할 수 있습니다.
이는 프로그램에 유료 코드 서명이 적용되지 않았기 때문입니다. 반드시 이
저장소의 공식 릴리스 페이지에서 받은 파일인지 확인한 다음 실행하세요.

## 14. 첫 설치가 오래 걸리는 이유

첫 설치 때 플래셔는 다음 작업을 자동으로 진행합니다.

- ESP32-S3와 플래시 용량 확인
- 필요한 설치 도구 다운로드
- 포켓몬 일반·이로치 스프라이트 다운로드
- 스프라이트의 투명 여백과 팔레트 정리
- 사용하지 않는 프레임 제거
- 추가 이미지와 선택한 음원 변환
- 연결된 기종용 펌웨어 생성
- 펌웨어 플래싱

인터넷 속도와 PC 성능에 따라 시간이 오래 걸릴 수 있습니다. 설치가 멈춘 것처럼
보여도 로그가 계속 추가되고 있다면 창을 닫거나 USB 케이블을 빼지 마세요.

두 번째 설치부터는 내려받은 파일과 가공 결과를 재사용하므로 시간이 줄어듭니다.

## 15. 내려받은 파일과 캐시 위치

플래셔가 내려받거나 만든 파일은 플래셔 옆의 다음 폴더에만 보관됩니다.

```text
TamaPoke-Flasher-Data
├─ Cache
├─ Payload
├─ Logs
└─ Backups
```

- `Cache`: 스프라이트, 변환한 자산과 생성된 펌웨어
- `Payload`: 설치에 필요한 프로그램
- `Logs`: 설치 과정 기록
- `Backups`: 저장 데이터 백업

캐시를 모두 지우고 처음부터 다시 진행하려면 플래셔를 종료한 뒤
`TamaPoke-Flasher-Data` 폴더를 삭제하면 됩니다.

## 16. 기존 저장 데이터 유지

기기에 기존 타마포케 한글판이 설치되어 있으면 플래셔가 저장 데이터를 유지할지
묻습니다.

저장 데이터를 남기면 다음 작업을 자동으로 수행합니다.

1. 기기의 저장 데이터를 PC로 백업합니다.
2. 기기를 초기화합니다.
3. 새 펌웨어를 설치합니다.
4. 저장 데이터를 복원합니다.
5. 기기를 재부팅합니다.

중요한 데이터가 있다면 설치 중 USB 케이블을 빼지 마세요. 원본 외국어
펌웨어나 다른 개조 펌웨어의 저장 데이터는 호환되지 않을 수 있습니다.

## 17. 자주 발생하는 문제

### Additional_assets.zip을 찾지 못했다고 나옵니다

`Additional_assets.zip`과 `TamaPoke-Flasher.exe`가 같은 폴더에 있는지
확인하세요. 파일 이름이 `sample_Additional_assets.zip`인 상태라면
`Additional_assets.zip`으로 바꿔야 합니다.

### 추가 자산이 누락되었다고 나옵니다

ZIP을 열고 `Visual`과 `Audio` 폴더가 들어 있는지 확인하세요. 파일 이름을
임의로 바꾸지 마세요.

### 음원 중복 오류가 나옵니다

같은 이름의 MP3와 WAV가 모두 들어 있습니다. 둘 중 하나만 남기세요.

### 기기가 표시되지 않습니다

다음을 확인하세요.

- ESP32-S3 기기의 화면이 켜져 있는가
- USB 케이블이 데이터 전송을 지원하는가
- 다른 USB 포트에서도 같은가
- Arduino 시리얼 모니터 등 다른 프로그램이 COM 포트를 사용 중이지 않은가

### 설치가 끝났는데 검은 화면입니다

몇 초 기다린 뒤 PWR 버튼을 눌러 보세요. 그래도 표시되지 않으면 USB 케이블을
분리했다가 다시 연결하세요.

### 이미지가 깨지거나 위치가 이상합니다

다음을 확인하세요.

- 이미지 크기와 파일명이 맞는가
- 투명해야 하는 이미지의 배경이 실제로 투명한가
- `S01~S03`의 캔버스와 그림 위치가 같은가
- `D01~D04`가 정확히 22×17인가
- `DD`가 정확히 22×16인가

### 새 이미지나 음원이 적용되지 않습니다

플래셔에서 `새로고침`을 누르고 표시된 자산 해시가 바뀌었는지 확인하세요.
그래도 이전 이미지가 나온다면 플래셔를 종료한 뒤 다음 폴더만 삭제하고 다시
시도할 수 있습니다.

```text
TamaPoke-Flasher-Data\Cache\additional
```

## 18. 배포 관련 주의

공개 플래셔와 소스에는 포켓몬 스프라이트가 포함되어 있지 않습니다. 포켓몬
스프라이트는 최종 사용자의 PC가 설치 과정에서 원본 제공처로부터 직접
내려받습니다.

플래셔가 만든 완성 펌웨어에는 다운로드한 스프라이트와 사용자가 넣은 이미지와
음원이 결합됩니다. 다음과 같은 완성 펌웨어 파일을 제3자에게 재배포하지 마세요.

```text
tamapoke-1.75-full.bin
tamapoke-1.75C-full.bin
```

다른 사람에게는 공개 플래셔, 샘플 ZIP과 이 설치 안내를 전달하고 각자의 PC에서
직접 설치하도록 안내하세요.
