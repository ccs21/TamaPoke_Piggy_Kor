# 법적·배포 구조 안내

이 문서는 공개 저장소와 플래셔가 어떤 자료를 포함하고, 어떤 자료를 최종
사용자의 PC에서 준비하는지 구분합니다. 법률 자문이 아니라 프로젝트의 실제
구조와 적용 라이선스를 설명하기 위한 문서입니다.

## 저장소와 공개 릴리스에 포함되는 자료

- MIT 조건으로 공개된 원본 TamaPoke 코드와 한글판 코드 수정분
- Windows 플래셔 소스와 ccs21이 직접 제작한 텍스트 전용 아이콘
- 자산이 없는 ESP32 기본 프로그램 조각
- 문서와 빌드 스크립트

## 포함되지 않는 자료

- 포켓몬 스프라이트 원본 및 가공본
- 사용자가 준비하는 추가 이미지와 음원
- 개인용 자산과 개인용 프로젝트
- 위 자산이 결합된 완성 펌웨어

## 설치 시 로컬에서 결합되는 자료

플래셔는 사용자의 PC에서 다음 작업을 수행합니다.

1. SpriteCollab 원본 저장소에서 필요한 스프라이트와 크레딧을 내려받습니다.
2. 필요한 프레임만 선택해 투명 여백과 팔레트를 최적화합니다.
3. 사용자가 준비한 `Additional_assets.zip`을 검사하고 이미지·음원을 변환합니다.
4. 자산 없는 기본 프로그램과 로컬 자산을 결합해 기종별 전체 펌웨어를 만듭니다.
5. 사용자가 연결한 기기에 그 펌웨어를 기록합니다.

사용자 자산은 외부 서버로 업로드하지 않습니다. 다운로드·가공·완성 결과는
플래셔 실행 파일 옆의 `TamaPoke-Flasher-Data`에 보관됩니다.

## 라이선스 경계

- `LICENSE`의 MIT 조건: 원본 프로젝트 코드와 한글판 코드 수정분
- SpriteCollab 스프라이트: 해당 프로젝트가 게시한 CC BY-NC 4.0과 제작자 표기
- 한글 비트맵 폰트: Noto Sans KR의 SIL Open Font License 1.1
- Arduino/.NET/NAudio 등: `THIRD_PARTY_NOTICES.md`에 표시한 각 라이선스
- 사용자 이미지·음원: 사용자가 실제로 보유한 권리와 원본의 이용 조건
- 포켓몬·다마고치 관련 명칭, 캐릭터, 디자인과 상표: 각 원권리자의 권리

오픈소스 라이선스는 라이선스 제공자가 허가할 수 있는 권리의 범위에만
적용됩니다. 다운로드 가능 여부나 변환 기능은 상표권·캐릭터 권리 또는 다른
권리까지 새로 허가한다는 뜻이 아닙니다.

## 완성 펌웨어 재배포 금지 안내

소스 코드 자체는 각 오픈소스 라이선스가 허용하는 범위에서 재배포할 수
있습니다. 그러나 플래셔가 만든 전체 펌웨어는 서로 다른 권리의 코드와 자산이
하나의 바이너리에 결합됩니다.

따라서 이 프로젝트는 사용자가 생성한 `*-full.bin`, 스프라이트 캐시,
`Additional_assets.zip`의 제3자 재배포를 허용하거나 권장하지 않습니다.
그러한 파일을 재배포하는 사람은 각 자산의 이용 조건, 제작자 표시와
원권리자의 문제 제기에 대한 책임을 직접 부담할 수 있습니다.
